Проектная документация приложения
=================================

Требования к первой версии приложения
------------------------------------

1. Развернут сервер на базе wsgiref.
2. Сервер принимает HTTP-запросы методом GET.
3. Сервер возвращает ответ браузеру.
4. Реализован класс Response - обертка HTTP-ответа.
5. Реализован класс Request - обертка HTTP-запроса.
6. Реализован декоратор @route.
7. Реализован класс BaseController. 
8. Реализован контроллер главной страницы.
