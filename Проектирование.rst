Проектная документация приложения
=================================

Требования к первой версии приложения
------------------------------------

1. Развернут сервер на базе wsgiref.
2. Сервер принимает HTTP-запросы методом GET.
3. Сервер возвращает ответ браузеру.
4. Реализован класс Response - обертка HTTP-ответа.
5. Реализован класс Request - обертка HTTP-запроса.
6. Реализован декоратор @route.
7. Реализован класс BaseController. 
8. Реализован контроллер главной страницы.

Требования ко второй версии приложения
------------------------------------

1. Реализован роутер.
2. Статусы вынесены в константы.
3. Производится ручной разбор ulr без сторонних библиотек.
4. Реализован шаблонизатор.

Требования к третьей версии приложения
------------------------------------

1. Произведено подключение базы данных (Sqlite3)
2. Созданы модели товаров и категорий.
3. Добавлен каталог товаров.

Требования к четвертой версии приложения
------------------------------------

1. Реализована обработка адреса /product/ID
2. Реализовано получение отдельного товара из БД.
3. Реализован шаблон страницы товара.
4. В каталоге добавлены ссылки на страницы товаров.
