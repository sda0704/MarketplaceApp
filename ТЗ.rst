Веб приложение "Интернет магазин"
=================================

.. contents:: Содержание
    :depth: 2

Функциональные требования
-------------------------

#. Каталог товаров.
    #. Просмотр главной страницы магазина.
    #. Просмотр списка всех товаров.
    #. Просмотр списка товаров по категориям.
    #. Просмотр сраницы отдельного товара.
    #. Поиск товара по названию.
    #. Сортировка товаров (по цене, названию).
#. Корзина.
    #. Добавление товара в корзину.
    #. Просмотр корзины.
    #. Изменение количества товаров в корзине.
    #. Оформление заказа.
#. Пользователи. 
    #. Регистрация пользователя.
    #. Вход в систему.
    #. Выход из системы.
    #. Просмотр истории заказов.
#. Администрирование. 
    #. Добавление нового товара.
    #. Изменение существующего товара.
    #. Удаление товара.


Нефункциональные требования
---------------------------

#. Приложение реализовано на языке Python.
#. Используются только стандартные библиотеки языка.
#. Веб-сервер реализован на модуле wsgiref.
#. Для работы с базой данных используется sqlite3. 
#. Интерфейс пользователя - графический.
#. Интерфейс реализуется с помощью JavaScript, HTML, CSS без использования сторонних библиотек.
#. Интерфейс не зависит от реализации.
#. Интерфейс реализует реакцию программы на действия пользователя.
